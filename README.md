# video-editing skill

Claude Code skill for AI-assisted video editing: cutting, structuring and augmenting real footage with FFmpeg, Remotion, ElevenLabs, fal.ai and a final pass in Descript or CapCut.

## Kurulum / Install

```bash
git clone https://github.com/smyzkrkc/video-olu-turucu.git
mkdir -p ~/.claude/skills
cp -r video-olu-turucu/skills/video-editing ~/.claude/skills/
```

Claude Code yeniden başlatıldığında `video-editing` skill'i otomatik yüklenir.
